# Nunito

`nunito-latin.ttf` is the genuine variable Nunito face from the Google Fonts repository, replacing the inherited static weight-900 file that had been declared as variable.

Source: https://raw.githubusercontent.com/google/fonts/main/ofl/nunito/Nunito%5Bwght%5D.ttf
License: SIL Open Font License 1.1, in OFL.txt.
Retrieved: 2026-10-01. The CSS deliberately uses weights 400–900.

## Manrope

`manrope-latin.ttf` is the original variable Manrope face, weights 200–800, used by the redesigned workspace and landing page.
Source: https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf
License: SIL Open Font License 1.1, in Manrope-OFL.txt. Retrieved: 2026-10-02.

## Instrument Serif

`instrument-serif.ttf` and `instrument-serif-italic.ttf` preserve OSS Mentor's heading typography on the contribution page only.
Source: Google Fonts Instrument Serif v5, https://fonts.google.com/specimen/Instrument+Serif.
License: SIL Open Font License 1.1, in InstrumentSerif-OFL.txt. Retrieved: 2026-10-07.
